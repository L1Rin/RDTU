# Supplementary PDF sources

[Repository home](../../README.md) · [Compiled PDF](../RDTU-Supplementary.pdf)

`main.tex` assembles the expanded scientific sections and Appendices A–G. Source prose, equations, bibliography and vector graphics come from the supplied full manuscript. Wide benchmark tables are reorganized by dataset, and source-reported ranking footers are kept separately. The changes to source interpretations are documented in the [source notes](../../docs/source-notes.md).

Compile from this directory with Tectonic:

```sh
tectonic main.tex
```

The published PDF uses Tectonic 0.17.0. Only manuscript sources are contained here.
