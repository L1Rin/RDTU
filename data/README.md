# Numerical tables

[Home](../README.md) · [Table index](../docs/tables.md)

Each CSV is a transcription of a manuscript table. Decimal strings and missing entries are retained. Full forecasting exports use `Dataset`, `Horizon`, `Model`, `MSE`, `MAE`; M4 exports use `Dataset`, `Metric`, `Model`, `Value`. The other files preserve their source table columns.

`Avg` is a source-reported horizon average, not a recomputed value. M4 `Average` is the source-reported weighted aggregate. Approximate costs are marked `≈`; unavailable entries retain `/` or `--`. All forecast error metrics are lower-is-better.
